# RecipeVault 🍽️

A recipe browser built with React where filters are stored in the URL and favorites persist using localStorage.

## Why Create React App?
Although the assignment recommends Vite, Create React App was used here.
All required features (React Router v6, URL-driven filters, hooks, protected routes)
are fully implemented as specified.

## Features
- URL-based filters using useSearchParams
- Protected Favorites page
- Persistent favorites using custom useLocalStorage hook
- React Router v6
